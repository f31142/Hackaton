# 전북이음

전북의 생활권, 가능한 시간, 관계 취향을 함께 살피는 소개팅 서비스 프로토타입.

배포: https://f31142.github.io/Hackaton/

## v3 · 지역에서 만나는 두 사람

흰색·핑크 기준 UI에 요청된 기능을 하나의 앱으로 통합했다. 이전 `upgrade`, `experience`, `revolution`, `tab-diff`, `ai-date-room`, `brand-fix`, `hero-people` 등의 화면 재작성 스크립트와 스타일을 index에서 로드하지 않는다. 이전 파일은 참조용으로 저장소에 남겨두고, 저장된 설문과 관심을 그대로 읽는다.

- SUIT 가변 폰트와 새 한글 `이음 / 전북이음` 워드마크, 오늘의 잇음 명칭.
- 14개 시·군의 19개 데이트 코스. 만나는 곳 → 선택 영화 → 식사 → 카페 → 지역 명소 → 선택 숙박. 섬/시내, 옥정호/치즈마을은 분리한다.
- 지역·상대·코스·날짜·시작 시간·영화·숙박을 바꾸고, 코스를 저장·불러오기·삭제·복사할 수 있다. 지도 링크로 실제 카페, 영화관, 숙박업소를 검색한다. 시간표는 예시이며 교통·영업시간 API와 연결되지 않았다.
- 프리미엄 아바타 코치: 상대 프로필, 두 사람의 공통 취향, 선택한 지역과 코스를 반영한다. 다정함/차분함/밝은 말투와 3가지 답변 상황으로 연습한다. 기본 문구와 실제 생성형 AI 브리핑을 분리한다.
- 월 9,900원은 출시 예정 요금안. 현재 버튼은 결제 없는 기능 체험을 켜고 끈다. 결제·구독·서버 측 유료 권한 확인은 아직 연결되지 않았다. 로컬 trial 값은 결제 권한이 아니다.
- MBTI 16유형 선택·자동 저장·프로필 표시. 후보 MBTI도 체험용 설정값이다. MBTI를 심리 진단이나 추천 점수에 사용하지 않는다.
- 사진 업로드·교체·삭제. JPG/PNG/WebP 10MB 이하, 실제 이미지 디코드 후 중앙 정사각형 640px WebP로 다시 인코딩한다. 사진은 AI 입력에 포함하지 않는다.
- 공식 발표/한국관광공사에서 확인한 2026년 축제 5개. 한국 날짜 기준 예정·진행 중 행사만 표시하고, 지역 필터·보관·달력 내보내기를 제공한다. ICS에는 하루 전 VALARM이 들어간다. 달력 앱에서 가져오기와 알림 허용이 필요하다. 백그라운드 웹 푸시를 가장하지 않는다.

데이터 파일은 `local-guide.js`, 저장/일정/추천 문구 로직은 `experience-core.js`, 화면은 `feature-ui.js`, 추가 스타일은 `features.css`다. 축제 일정의 확인일은 2026-09-12이며 실시간 동기화는 아니다. 각 카드의 공식 일정 링크로 재확인할 수 있다. 다음 연도 일정은 확인 후 데이터를 업데이트해야 한다.

`ieum:features:v3`는 사진·MBTI·체험 상태·현재 코스·저장 코스·축제 보관을 저장한다. 첫 실행 시 이전 `ieum:extra:v1`의 사진/MBTI를 읽는다. 기존 `meetrust:v2`의 설문·관심·숨김·약속 초안도 유지하며 초기화 시 두 버전의 정보 모두 비운다.

## 기본 기능

- 사진과 추천을 바로 볼 수 있는 모바일 중심 UI, 자체 호스팅 SUIT 가변 폰트.
- 오늘의 잇음 / 관심 / 데이트 / 내 프로필. 대형 홍보 섹션, 지인 보증, 신뢰 점수, 고정된 AI 결과 제거.
- 검증되는 3단계 설문: 성인 나이, 닉네임, 전북 14개 시군 생활권, 가능 시간, 관심사, 5개 성향 질문, 자유 서술.
- 응답에 따라 바뀌는 추천 정렬 및 성별·나이·생활권·시간 필터, 실제 응답에서 계산한 공통점.
- 관심 저장/취소, 프로필 숨김/복원, 편집 가능한 첫 대화 초안, 상호 생활권과 시간의 교집합으로 만드는 약속 초안.
- localStorage 저장과 데이터 초기화, 키보드 조작 가능한 네이티브 dialog, 오류·빈 결과·로딩·취소 처리.

## 생성형 AI

`ai.js`와 `ai-worker.js`는 **WebLLM 0.2.85 + Qwen3-0.6B**를 실제로 호출한다. 모델 다운로드에 동의하는 버튼을 누른 뒤 Web Worker / WebGPU에서 추론한다. API 키와 AI 서버가 필요하지 않다. 성향 노트, 두 사람의 공통점 해설, 첫 대화 문구와 프리미엄 아바타 브리핑을 생성한다. 자유 서술도 프롬프트에 반영한다. 닉네임과 나이는 프롬프트에서 제외한다.

첫 실행에는 수백 MB 모델 다운로드와 약 1.4~2 GB의 GPU 메모리가 필요할 수 있다. 지원 브라우저/그래픽 장치/네트워크 상태에 따라 이용이 제한된다. CDN 또는 모델 호스트가 차단되면 실제 오류를 표시하며, 미리 작성한 문구를 AI 생성 결과인 것처럼 표시하지 않는다. 생성 실패/취소에도 기본 추천은 유지된다. AI 결과는 심리 진단이나 관계 성공 확률이 아니다.

기본 추천은 `core.js`의 결정적 비교 규칙이다. 성향 일치 문항당 6, 공통 관심사당 4(최대 12), 생활권 교집합 25, 가능 시간 교집합 25, 같은 시군 8을 내부 정렬에 사용한다. 이 값은 내부 우선순위이며 UI에 신뢰도·궁합 확률로 노출하지 않는다. 같은 응답 수와 공통 시간대 수만 관찰 가능한 수치로 표시한다.

## 실행 및 테스트

별도 프런트엔드 빌드나 npm 설치가 필요 없는 ES 모듈 정적 사이트다.

```sh
npm start
# http://localhost:4173
npm test
```

GitHub Actions의 기존 `.github/workflows/pages.yml`이 `main` 업데이트를 Pages에 배포한다.

## 체험 버전의 범위

모든 추천 후보와 후보 사진은 가상 인물이다. 내 사진은 사용자가 선택한 파일을 이 브라우저에만 보관한다. 사용자 가입·본인 인증·실제 채팅·예약·실제 사용자 DB는 연결되어 있지 않다. 관심은 나만 보는 저장 목록이며 메시지는 복사 가능한 초안이다. 약속 초안은 상대에게 전송되지 않는다. 설문·관심·숨김·약속 초안은 이 브라우저의 `meetrust:v2` 키에 저장된다. 실제 사업화 시 서버 인증, 동의 기반 프로필 공개 및 매칭, 신고 처리와 데이터 관리 구조를 별도로 구현해야 한다.

## 오픈소스 및 이미지

- SUIT variable font: https://github.com/sun-typeface/SUIT (SIL OFL 1.1, `assets/SUIT-LICENSE.txt`). 폰트 파일은 자체 호스팅한다.
- WebLLM: https://github.com/mlc-ai/web-llm (Apache-2.0), 실행 시 고정 버전을 동적 로드한다.
- Qwen3-0.6B MLC: https://huggingface.co/mlc-ai/Qwen3-0.6B-q4f16_1-MLC.
- `assets/profiles.webp`: 내장 imagegen으로 만든 6명의 가상 성인 프로필 사진. 원본 3열×2행 이미지를 CSS에서 영역별로 사용한다. 원본은 웹 전송용 WebP로 변환했다.
- 생성 프롬프트 요약: 3열×2행, 각 칸 정사각형의 서로 다른 가상 한국인 성인 6명(여성 3명, 남성 3명), 자연광 카페·책방·공원 배경, 일상복, 자연스러운 스마트폰 인물 사진, 글자·여백·UI 없음.

## 검증 범위

추천 결과 변화, 필터, 응답 교집합, 프로필 유효성, 저장 실패 복구, 입력 이스케이프, AI 입력 구성은 Node 테스트로 확인한다. 생성형 AI는 실행 환경과 모델 다운로드가 모두 가능한 기기에서 별도 실동작 확인이 필요하다.

추가 테스트는 14개 지역 코스, 영화/숙박 선택과 날짜 경계, 이전 저장값 마이그레이션, 사진 형식 및 크기 거부, 선택 상대/말투/상황 반영, 프리미엄 체험 게이트, 한국 날짜의 축제 필터, ICS 날짜/알림/UTF-8 줄 접기를 확인한다.
