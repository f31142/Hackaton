# MEETRUST 전북

전북의 생활권, 가능한 시간, 관계 취향을 함께 살피는 소개팅 서비스 프로토타입.

배포: https://f31142.github.io/Hackaton/

## 이번 버전

- 사진과 추천을 바로 볼 수 있는 모바일 중심 UI, 자체 호스팅 SUIT 가변 폰트.
- 오늘의 추천 / 관심 / 데이트 / 내 프로필. 대형 홍보 섹션, 지인 보증, 신뢰 점수, 고정된 AI 결과 제거.
- 검증되는 3단계 설문: 성인 나이, 닉네임, 전북 14개 시군 생활권, 가능 시간, 관심사, 5개 성향 질문, 자유 서술.
- 응답에 따라 바뀌는 추천 정렬 및 성별·나이·생활권·시간 필터, 실제 응답에서 계산한 공통점.
- 관심 저장/취소, 프로필 숨김/복원, 편집 가능한 첫 대화 초안, 상호 생활권과 시간의 교집합으로 만드는 약속 초안.
- localStorage 저장과 데이터 초기화, 키보드 조작 가능한 네이티브 dialog, 오류·빈 결과·로딩·취소 처리.

## 생성형 AI

`ai.js`와 `ai-worker.js`는 **WebLLM 0.2.85 + Qwen3-0.6B**를 실제로 호출한다. 모델 다운로드에 동의하는 버튼을 누른 뒤 Web Worker / WebGPU에서 추론한다. API 키와 AI 서버가 필요하지 않다. 성향 노트, 두 사람의 공통점 해설, 첫 대화 문구를 생성한다. 자유 서술도 프롬프트에 반영한다. 닉네임과 나이는 프롬프트에서 제외한다.

첫 실행에는 수백 MB 모델 다운로드와 약 1.4~2 GB의 GPU 메모리가 필요할 수 있다. 지원 브라우저/그래픽 장치/네트워크 상태에 따라 이용이 제한된다. CDN 또는 모델 호스트가 차단되면 실제 오류를 표시하며, 미리 작성한 문구를 AI 생성 결과인 것처럼 표시하지 않는다. 생성 실패/취소에도 기본 추천은 유지된다. AI 결과는 심리 진단이나 관계 성공 확률이 아니다.

기본 추천은 `core.js`의 결정적 비교 규칙이다. 성향 일치 문항당 6, 공통 관심사당 4(최대 12), 생활권 교집합 25, 가능 시간 교집합 25, 같은 시군 8을 내부 정렬에 사용한다. 이 값은 내부 우선순위이며 UI에 신뢰도·궁합 확률로 노출하지 않는다. 같은 응답 수와 공통 시간대 수만 관찰 가능한 수치로 표시한다.

## 실행 및 테스트

별도 프런트엔드 빌드나 npm 설치가 필요 없는 ES 모듈 정적 사이트다.

```sh
npm start
# http://localhost:4173
npm test
```

GitHub Actions의 기존 `.github/workflows/pages.yml`이 `main` 업데이트를 Pages에 배포한다.

## 체험 버전의 범위

모든 후보와 사진은 가상 인물이다. 사용자 가입·본인 인증·실제 채팅·예약·실제 사용자 DB는 연결되어 있지 않다. 관심은 나만 보는 저장 목록이며 메시지는 복사 가능한 초안이다. 약속 초안은 상대에게 전송되지 않는다. 설문·관심·숨김·약속 초안은 이 브라우저의 `meetrust:v2` 키에 저장된다. 실제 사업화 시 서버 인증, 동의 기반 프로필 공개 및 매칭, 신고 처리와 데이터 관리 구조를 별도로 구현해야 한다.

## 오픈소스 및 이미지

- SUIT variable font: https://github.com/sun-typeface/SUIT (SIL OFL 1.1, `assets/SUIT-LICENSE.txt`). 폰트 파일은 자체 호스팅한다.
- WebLLM: https://github.com/mlc-ai/web-llm (Apache-2.0), 실행 시 고정 버전을 동적 로드한다.
- Qwen3-0.6B MLC: https://huggingface.co/mlc-ai/Qwen3-0.6B-q4f16_1-MLC.
- `assets/profiles.webp`: 내장 imagegen으로 만든 6명의 가상 성인 프로필 사진. 원본 3열×2행 이미지를 CSS에서 영역별로 사용한다. 원본은 웹 전송용 WebP로 변환했다.
- 생성 프롬프트 요약: 3열×2행, 각 칸 정사각형의 서로 다른 가상 한국인 성인 6명(여성 3명, 남성 3명), 자연광 카페·책방·공원 배경, 일상복, 자연스러운 스마트폰 인물 사진, 글자·여백·UI 없음.

## 검증 범위

추천 결과 변화, 필터, 응답 교집합, 프로필 유효성, 저장 실패 복구, 입력 이스케이프, AI 입력 구성은 Node 테스트로 확인한다. 생성형 AI는 실행 환경과 모델 다운로드가 모두 가능한 기기에서 별도 실동작 확인이 필요하다.
